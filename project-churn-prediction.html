Disclaimer

This project was completed for educational and analytical purposes using synthetic data. The findings and model performance are illustrative and should not be interpreted as actual business results or predictions about real customers.

Project Background

Customer churn can affect recurring revenue and long-term customer relationships. This project explores how machine learning can help identify customers with elevated churn risk and support targeted retention planning.

Methodology

The workflow included exploratory data analysis, feature engineering, model comparison, model evaluation, and interpretation of predictions using SHAP.

Tools: Python, Google Colab, Pandas, Scikit-learn, XGBoost, SHAP

Results

The project evaluated machine learning models for churn prediction and explored a risk-based approach to customer retention prioritization.

0.956 ROC-AUC after in-context learning on MDLC2

The findings demonstrate how model evaluation and explainability can inform a structured retention workflow.
